## 📌 Project Overview
This project demonstrates a secure file sharing system where files are encrypted using AES (Advanced Encryption Standard) before being stored and decrypted during download. The goal is to ensure secure data handling and confidentiality.

---

## 🛠️ Technologies Used
- Python Flask (Backend Framework)
- AES Encryption (PyCryptodome)
- HTML / CSS (Frontend)
- Git & GitHub (Version Control)

---

## 🔐 System Workflow
1. User uploads a file through the web interface  
2. The file is encrypted using AES  
3. Encrypted file is stored securely on the server  
4. File is decrypted only when a download is requested  

---

## ✅ Security Features
- AES encryption for files at rest  
- Secure encryption key handling  
- File integrity maintained  
- Secure upload and download functionality
